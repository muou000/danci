# 按真题考频划分正文色块，短文取消四六级篇目分级并统一语料列表

《全国大学英语四、六级考试大纲（2016年修订版）》词表（`outline.pdf`）原生通过 `★` 区分四级与六级词目，但若直接将 `★` 词标为视觉权重最高的橙色，会让低频六级生僻词挤占高频四级核心词的注意力。我们决定在正文色块上对齐样图心智：剔除免注基础词后，按历年四六级真题词频将排名前 25%–30% 的核心大纲词目划为橙色“高频词”，其余核心大纲词目划为绿色“普通大纲词”（图例名“单词”），搭配黄色“短语”与极少量兜底的淡紫色“超纲词”。

在短文组织上，由于每篇短文在真实语境表达中均自然包含了四级与六级词汇，不再人为划分为“四级核心篇”与“六级进阶篇”。短文库（含正式纳入的示范短文）以题材分类（常考题材与具体题材）统一管理，取消目录与界面的难度分级筛选，确保学习者在连贯的双栏精读中全面覆盖考纲词汇。
