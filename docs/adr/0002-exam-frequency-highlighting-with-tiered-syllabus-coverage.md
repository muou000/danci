# 按真题考频划分正文色块，并在短文编排上按四六级分阶全覆盖

《全国大学英语四、六级考试大纲（2016年修订版）》词表（`outline.pdf`）原生通过 `★` 区分四级与六级词目，但若直接将 `★` 词标为视觉权重最高的橙色，会让低频六级生僻词挤占高频四级核心词的注意力。我们决定在正文色块上对齐样图心智：剔除免注基础词后，按历年四六级真题词频将排名前 25%–30% 的核心大纲词目划为橙色“高频词”，其余核心大纲词目划为绿色“普通大纲词”（图例名“单词”），搭配黄色“短语”与极少量兜底的淡紫色“超纲词”；与此同时，利用短文编排顺序（前段“四级核心篇”+ 后段“六级进阶篇”）承接原大纲的四六级难度梯度，确保全部核心大纲词目（含 100% 的 `★` 六级词目）至少完成一次独立标注覆盖。
