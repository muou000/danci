# 行间词义体例规范与正文平齐防重叠排版

在双栏英语阅读精读界面中，学习者依赖短文正文中的行间中文释义进行语境化词汇记忆。为了还原专业精读学习出版物（参考样图 `sample.png`）的版式质感与学习深度，我们确立以下排版与词义编纂决策：

1. **义项密度（2~3 个核心义项）**：单词行间释义严禁截断为单一孤立义，必须尽量提供 2 至 3 个贴合语境的核心常考义项（以中文全角分号 `；` 分隔），帮助学习者在阅读中掌握词汇多义与同义替换。
2. **语法体例与语境词性匹配**：所有形容词（`a.` / `adj.`）义项严格统一带“的”（如 `a.经典的；典范的`），所有副词（`ad.` / `adv.`）义项严格统一带“地”（如 `ad.相应地；必然地`）；标注的词性必须精准匹配单词在当前句子中的实际语法角色，严禁出现将修饰语误标为名词（如 `classic texts` 中 `classic` 误标为名词“经典”、`individual awareness` 中 `individual` 误标为名词“个人”）或将修饰对象的名词误标为形容词（如 `green habits` 中 `habits` 误标为形容词）。
3. **正文自然排版与平齐基线**：正文英文单词统一采用两端对齐（`text-align: justify; text-justify: inter-word;`）与平齐基线（`vertical-align: baseline`），西文单词间距由正文排版引擎自然驱动，绝不允许因下方释义宽窄而拉伸正文词距或破坏平直基线（严禁正文单词忽高忽低或跳动）。
4. **编译期弹性微调消除重叠**：针对相邻生词多义项释义总宽可能超过单词间距的问题，不采用破坏正文排版的单行硬拉伸或让释义错落多行的做法，而是在语料编译期通过弹性间隙松弛算法（`calculateAnnotationShifts`）自动计算相邻注释的微距偏移（`shiftX`），配合 CSS `transform: translateX(calc(-50% + ${shiftX}px))`，在正文单词完全不动的前提下，确保下方中文释义之间始终保持至少 5px~6px 的清晰纯净间距，彻底消除视觉重叠。
