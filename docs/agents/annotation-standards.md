# 行间词义体例与排版规范 (Annotation & Typography Standards)

本文档规范短文语料编纂、行间标注生成及 UI 正文排版的质量准则。所有 Agent 在编写或更新短文语料时，必须遵循以下编写和验收规则；调整排版组件时，必须遵循后续五项排版与标注准则。

## 短文编写与全局验收
- **Issue 粒度**：每个单篇 Issue 只交付一篇短文；总 Issue 跟踪全语料覆盖目标，并在全部短文完成后安排最终覆盖验收。
- **单篇规划**：起草前确定主题与短文目标词目。词目按主题及其自然语境选择，不按字母顺序、前缀或固定批次分配；每个词目都必须能在主题中自然使用。首字母分布可提示复查，但不单独作为验收条件。
- **待覆盖词目清单**：起草前运行 `npm run coverage`，读取 `docs/corpus/uncovered-headwords.md`，从尚未覆盖的词目中按主题和自然语境挑选目标词；完稿后再次运行以刷新清单。清单由大纲词表与短文行间标注生成，不手工编辑。
- **篇幅与结构**：短文保持 3–4 段、190–280 个英文词（严格不得超出 280 词上限）。
- **单篇覆盖增长率建议指标（推荐 $\ge 1.0\%$）**：
  - 为避免单篇覆盖词汇过少，建议每篇短文**单篇净增未覆盖核心大纲词目增长率尽量达到 1.00% 左右**（以全库非免注核心大纲词为基准计算），作为推荐引导指标而非强制硬性指标。
  - 编写时充分利用篇幅容量，在保证表达自然地道的前提下，有机融入未覆盖大纲词，避免被大量低阶免注词或已被多次覆盖的旧词过多稀释。
- **自然连贯与语法严谨性优先**：
  - 提升覆盖率必须以**英文语法正确性、主题逻辑自然连贯、语域得体**为绝对前提。严禁为了硬凑词目而生硬堆砌、破坏主谓逻辑、制造悬空分词（Dangling Participles）或遗漏必要限定词。
- **独立 SubAgent Peer Review 审校流程**：
  - 每篇短文在编写或重大优化完成后，必须调用独立 SubAgent（`invoke_subagent`）执行严肃的同行审校（Peer Review）。
  - 审校清单必须逐项核查：
    1. **语法与连贯性**：主谓一致、时态协调一致、逻辑主语对齐（严防悬空分词）、可数单数名词限定词完整、并列结构对称；
    2. **篇幅与增长率**：词数严格在 190–280 词之间；单篇净增未覆盖核心大纲词目增长率建议达标（推荐 $\ge 1.0\%$，优先保证自然连贯与语法正确）；
    3. **行间词义标注规范**：2~3 个常考核心义项（全角分号 `；` 分隔）；形容词 `a.` 100% 以“的”结尾；副词 `ad.` 100% 以“地”结尾；名词前作定语 100% 准确标注为 `a.` 形容词；
    4. **同形异义词目对齐**：严格区分大纲中带上标/序号的同形异义词目（如 `bank²`、`wind²`、`lead²`），杜绝词目张冠李戴；
    5. **中英对照翻译**：逐句译文忠实精炼无漏译误译，摆脱生硬翻译腔，且与行间释义高度吻合互证；
    6. **拓展条目**：12–18 条高质量拓展，解析详尽准确。
  - 只有当独立 SubAgent 审校结论明确给出 **【APPROVED】**，且全量自动化测试（`corpus.test.ts`、`npm test`、`npm run build`）全部通过后，方可正式合并交付。
- **全语料覆盖**：所有短文完成后，统计全部非免注核心大纲词目的覆盖情况，包含四级核心词与标星六级词；未覆盖词目应通过主题合适的短文补齐或修订，直到覆盖率达到 100%。不以批次分配结果代替全语料验收。

## 1. 释义丰富度（尽量 2~3 个义项）
- **禁止单义截断**：每个单词的行间释义必须尽量提供 2 至 3 个贴合语境的核心义项（以中文全角分号 `；` 分隔），不可为了缩减字符宽度而删减至单一孤立义项。
- **体例要求**：
  - 正确：`a.现代的；新式的`、`v.改变；使改观；转化`、`a.经典的；典范的`
  - 错误：`a.现代的`、`v.改变`、`a.经典的`（义项过少，不满足背单词学习深度）
- **正则约束**：语料校验引擎严格通过 `WORD_GLOSS_REGEX = /^(?:n|v|vt|vi|a|adj|ad|adv|prep|conj|pron|num)\.\s*[^；\s][^；]*(?:；\s*[^；\s][^；]*){1,2}$/` 强制检查。

## 2. 词缀规范（形容词带“的”，副词带“地”）
- **形容词（`a.` / `adj.`）**：每一个义项必须以“的”结尾。
  - 正确：`a.迅速的；快捷的`、`a.日常的；每日的`、`a.固有的；内在的`
  - 错误：`a.迅速；快捷`、`a.日常；每日`、`a.固有；内在`
- **副词（`ad.` / `adv.`）**：每一个义项必须以“地”结尾。
  - 正确：`ad.相应地；必然地`
  - 错误：`ad.因此；相应`、`ad.因此；相应地`（首项缺“地”）

## 3. 语境词性匹配（Contextual Part of Speech）
- **按句法功能定词性**：行间标注展示的是生词在**当前句子中的实际语法角色**，严禁机械套用词典第一词性。
  - **名词前作定语的词**：若起修饰作用，必须标注为形容词。例如 `classic texts` 中 `classic` 必须为 `a.经典的；典范的`（而非名词 `n.经典`）；`individual awareness` 中 `individual` 必须为 `a.个人的；个体的`。
  - **被修饰的名词**：即使原形在词典中常见为动词/形容词，在句中作名词时必须标注为名词。例如 `green habits` 中 `habits` 必须为 `n.习惯；习性`（严禁误标为形容词）；`cognitive autonomy` 中 `autonomy` 必须为 `n.自主权；独立性`。

## 4. 正文排版与平齐基线（Typography & Baseline Consistency）
- **正文基线平齐**：英文正文单词及标注包裹容器必须统一使用 `vertical-align: baseline`，确保整行西文字符处于同一水平基线，严禁上下跳动、忽高忽低。
- **正文词距自然均匀**：英文正文容器配置 `text-align: justify; text-justify: inter-word;`，单词间距完全由西文排版规则驱动。严禁让绝对定位的中文释义撑大、压缩或不规则拉伸正文英文单词间距。

## 5. 行间注释防重叠（Collision-Free Micro-Nudge）
- **物理绝对互斥**：在任何字体渲染与分辨率下，正文下方的相邻中文释义严禁发生水平文字交叉或重叠遮挡。
- **弹性微调机制（`shiftX`）**：在语料编译期（`compilePassage`），通过 `calculateAnnotationShifts` 预先估算英文词宽与中文释义宽度；当相邻释义因多义项存在水平挤压风险时，通过双向弹性松弛微调下方释义的水平偏移量（`shiftX`），配合 CSS `transform: translateX(calc(-50% + ${token.shiftX}px))` 保证相邻释义间保留至少 5px~6px 净间隙，同时正文英文单词保持原位不动。

## 6. 语法与句法高频陷阱防范 (Grammar & Syntax Integrity)
- **时态协调与叙事基准**：段落应确立清晰的基准时态（如叙事性以一般过去时为主，客观论述以一般现在时为主）。除明确的时间状语从句或转折对比外，严禁在同一分句或段落中随意跳跃时态或混合矛盾时态。
- **限定词完备性**：单数可数名词在句中严禁“裸露”，必须搭配不定冠词（`a/an`）、定冠词（`the`）、物主限定词（`its/their/our`）或指示代词；不可随意省略泛指或特指限定词。
- **悬空分词绝对禁止（No Dangling Modifiers）**：位于句首或句尾的分词短语（如 `Having done...`、`V-ing...`、`V-ed...`），其逻辑主语必须与主句的语法主语绝对一致，不可出现逻辑主语指向动作受体或无关实体的语法脱节。
- **并列结构平齐（Parallelism）**：由 `and`、`or`、`as well as`、`both... and...` 等连接的词组或分句，其词性、非谓语结构（不定式 vs 动名词）及语态须保持对称平衡，严禁并列失衡。

## 7. 中文翻译忠实度与地道表达 (Translation Fidelity & Natural Phrasing)
- **忠实语境原意，杜绝望文生义与错译**：整句翻译必须基于篇章语境精准传达深层句意与逻辑，严禁死扣个别词语的表面常见含义进行机械硬套，杜绝生造句意或反向扭曲原意。
- **行间释义与整句翻译内生契合**：单个生词的行间 2~3 个核心释义，必须与该句的中文整句翻译互相呼应并能够得到逻辑印证；严禁出现“行间写 A 义项，整句翻译却使用完全冲突或不相干的 B 义”之情况。
- **语言地道，祛除生硬“翻译腔”**：中文翻译应契合中文阅读习惯，适当调整被动语态为主动表达，合理拆分过长的定语从句或从属分句，使文句晓畅、语义清晰、用词准确。

## 8. 同形异义词与大纲词目精准对齐 (Homograph Disambiguation & Headword Alignment)
- **严格区分带序号的大纲分立词目**：大纲词表中，部分同形异义词被划分为不同的词目条目（如 `bank` [银行] 与 `bank²` [河岸]；`wind` [风] 与 `wind²` [蜿蜒；缠绕]；`lead` [引领] 与 `lead²` [铅]；`light` [光] 与 `light²` [点亮] 等）。
- **精准核对词目映射**：在为课文生词标记 `headword` 或拓展词汇时，必须查验该词在语境中的词义在大纲原表中归属于哪一个具体词目，绝不可混淆同形异义条目，以保证全库大纲词汇覆盖统计与学习者查阅检索的 100% 准确性。
